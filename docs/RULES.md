# 三国象棋 · 规则（v0.2）

魏、蜀、吴三人对弈的象棋变体。走法尽量沿用中国象棋，三方的差异只来自**各自一种特色棋子**，没有主动技能。

![棋盘](./screenshot.png)

## 一、棋盘

棋盘由三块本土、三条河道、中央的荆州和三处边境山脉组成，方位与真实地理一致：

| 区域 | 位置 | 说明 |
|---|---|---|
| 魏本土 | 北（上） | 9 路 × 5 线，含九宫，与普通象棋的半张棋盘相同 |
| 吴本土 | 东南（右下） | 同上 |
| 蜀本土 | 西南（左下） | 同上 |
| 河道 | 每方本土正前方的中间五路 | 魏前汉水，吴前长江，蜀前川江；三条河环绕荆州 |
| 荆州 | 中央 | 有襄阳、江陵、江夏三座城 |
| 边境山脉 | 两家之间 | 魏蜀之间秦岭，魏吴之间大别山，吴蜀之间巫山 |

### 「折线」网格

每一方往前看，棋盘就是一张普通的象棋盘，只是过河以后：

- **左半边的路**一直往前走，会穿过荆州进入**左手邻国**的右半边，最后到达对方底线；
- **右半边的路**同理通向**右手邻国**；
- **中路**穿过棋盘中心，接上另外两家之间的交界线。

除中心点有 6 个方向以外，其余每个点和普通象棋一样只有上下左右四个方向，所以车、马、炮、兵都按原来的方式走，只需记住「直线在中心折弯」。棋盘上画出的实线就是棋子能走的直线。

## 二、地形

**山（三处边境）不可通行**
- 任何棋子都不能进入山里。
- 车、炮的直线走到山前为止；炮弹也飞不过山。
- 马的落点不能在山里；马腿在山上时也跳不过去。

画面上通向山里的线是虚线，表示走不通。

**河道**本身不挡路，谁都可以走进河里或穿过河道。它只对两种特色棋子有特殊效果（见下）。

## 三、棋子与走法

每方 16 子，摆法与普通象棋相同。

| 棋子 | 走法 | 与普通象棋的差别 |
|---|---|---|
| 主公（魏/蜀/吴） | 九宫内直走一步 | **没有「将帅对脸」的限制** |
| 士 | 九宫内斜走一步 | 无 |
| 象 | 走「田」字，塞象眼，不能过河 | 无 |
| 车 | 沿直线走任意格 | 被山挡住 |
| 马 | 走「日」字，蹩马腿 | 被山挡住 |
| 炮 | 平移同车，隔一子打 | 被山挡住 |
| 兵 | 未过河只能直进一步；过河后可前进、横走，**还可以后退** | 普通兵能后退（藤甲兵除外） |

「过河」指离开自己的本土（走进河道就算过河）。兵在别家本土时，朝那一家的底线方向为「前」。

几个三人棋盘才有的细节：

- **车、炮穿过中心**会继续沿同一条直线走（画面上是笔直的）。
- **马跳经过中心**时，只能落在中心正前方那条线两侧的两个点上，和普通位置一样只有两个落点。

## 四、三方特色棋子

**魏 · 虎豹骑（马，棋子上写「骑」）**
- 不受蹩马腿限制。
- 但不能一跳越过河道：马腿落在河里的跳法不行。必须先跳进河里，下一步再上岸。往回撤时也一样。
- 山照样挡得住骑兵。

**蜀 · 藤甲兵（兵，棋子上写「藤」）**
- 刀枪不入：**不能被兵吃掉**。车、马、炮等其他棋子照常可以吃。
- 藤甲沉重，只进不退：过河后可前进、横走，不能后退（就是普通象棋里兵的走法）。

> 演义里的藤甲兵本是南蛮乌戈国兀突骨的部队，这里设定为蜀平定南中后收编。

**吴 · 巡河炮（炮）**
- 吴炮在**自家河道（长江，吴本土正前方）**里平移时不受棋子阻挡，可以一步走到这条河上的任意空位。
- 吃子仍按普通炮，要隔一个炮架。在别家的河里就是普通的炮。

## 五、行棋与胜负

- **行棋顺序**：蜀 → 吴 → 魏。
- **不能送将**：走完后，自己的主公不能处在任何对手的攻击之下。
- **吃将制**：三人局中，一家的走法可能让另一家直接吃到你的主公，你来不及应将。所以以「主公被吃」判定出局，而不是「将死」。
- **归降**：主公被吃的一方出局，其余棋子全部归降吃将者，并保留原有特性（例如吴吃掉魏主公后，接管的虎豹骑仍然不怕蹩马腿）。归降的棋子右上角有原势力颜色的小圆点。
- **困毙**：轮到你时无棋可走，你出局，残部归降上一个行棋者。
- 出局一方的回合直接跳过。

获胜条件（任一）：

1. **一统天下**：只剩你一家。
2. **荆州霸业**：轮到你时，襄阳、江陵、江夏三座城上都站着你的棋子。也就是说，你要在三城驻军，并顶住两个对手各一步的反扑。
3. **回合上限**：各走 150 步（共 450 步）仍未分胜负时计分：子力（车 9、炮 4.5、马 4、士 2、象 2、兵 1）+ 每面城旗 3 分。棋子走上城池就插上己方旗帜，离开后旗帜仍在。

## 六、待试玩调整的参数

下面这些都是凭直觉定的，需要实际对局后再调：

- 回合上限（`MAX_PLY`）、城旗分值（`CITY_SCORE`）、行棋顺序（`TURN_ORDER`），在 `src/engine/factions.ts`；
- 河道和山的位置与宽度（`RIVER_RANK`、`EDGE_FILES`）、城池位置（`CITY_RANK`），在 `src/engine/board.ts`；
- 巡河炮是否太弱（目前只在长江里有用，偏防守）；
- 藤甲兵「只防兵」是否过弱；
- 荆州霸业是否过易或过难。

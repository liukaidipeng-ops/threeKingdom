# 三国象棋 · 规则（v0.1）

魏、蜀、吴三人对弈的象棋变体。走法尽量沿用中国象棋，三方的差异来自**地形**和**兵种特性**。

![棋盘](./screenshot.png)

## 一、棋盘

棋盘由三块本土、三条边境和中央的荆州组成，方位与真实地理一致：

| 区域 | 位置 | 说明 |
|---|---|---|
| 魏本土 | 北（上） | 9 路 × 5 线，含九宫，与普通象棋的半张棋盘相同 |
| 吴本土 | 东南（右下） | 同上 |
| 蜀本土 | 西南（左下） | 同上 |
| 荆州 | 中央 | 平原，有襄阳、江陵、江夏三座城 |
| 秦岭 | 魏—蜀之间 | 山地 |
| 长江 | 魏—吴之间 | 水域 |
| 三峡 | 吴—蜀之间 | 蜀侧为山地，吴侧与江面为水域 |

### 「折线」网格

每一方往前看，棋盘就是一张普通的象棋盘，只是过河以后：

- **左半边的路**（左手边四路）一直往前走，会进入**左手邻国**的右半边，最后到达对方底线；
- **右半边的路**同理通向**右手邻国**；
- **中路**穿过棋盘中心，接上另外两家之间的交界线。

三条交界线（前沿线）在中心交汇。除中心点有 6 个方向以外，其余每个点和普通象棋一样只有上下左右四个方向，所以车、马、炮、兵都按原来的方式走，只需记住「直线在中心折弯」。棋盘上画出的线就是棋子能走的直线。

## 二、棋子与走法

每方 16 子，摆法与普通象棋相同。

| 棋子 | 走法 | 与普通象棋的差别 |
|---|---|---|
| 主公（魏/蜀/吴） | 九宫内直走一步 | **没有「将帅对脸」的限制** |
| 士 | 九宫内斜走一步 | 无 |
| 象 | 走「田」字，塞象眼，不能过河 | 无 |
| 车 | 沿直线走任意格 | 受地形限制（见下） |
| 马 | 走「日」字，蹩马腿 | 受地形限制；魏马有特性 |
| 炮 | 平移同车，隔一子打 | 平移受地形限制，隔子打不受；不能打藤甲兵 |
| 兵 | 未过河直进一步；过河后可进可横走，不能后退 | 「前进」= 远离自己的老家 |

几个三人棋盘才有的细节：

- **车、炮穿过中心**会继续沿同一条直线走（画面上是笔直的）。
- **马跳经过中心**时，只能落在中心正前方那条线两侧的两个点上，和普通位置一样只有两个落点。
- **兵站在中心**时，除了退回来路，其余 5 个方向都能走。
- 兵在别家本土时，朝那一家的底线方向为「前」，左右为「横」。

## 三、地形

| 地形 | 谁能自由通行 | 其他势力 |
|---|---|---|
| 山地（秦岭、三峡蜀侧） | 蜀军 | 车、炮进入山地必须停下（可以停在山地里，但不能一次穿过）；马不能跳上山地 |
| 水域（长江、三峡吴侧与江面） | 吴军 | 车、炮进入水域必须停下；马不能跳进水域 |
| 平地 | 所有人 | 无限制 |

炮「隔子打」时炮弹飞越地形，只看炮架。兵不受地形影响；士、象、主公不出本土，也不受影响。

## 四、三方特色

**魏 · 虎豹骑**
- 魏马（棋子上写「骑」）在**平原**（魏本土与荆州）上不受蹩马腿限制。
- 劣势：通往蜀、吴的边境都是山地或水域，铁骑过不去，只能从荆州绕行。

**蜀 · 藤甲兵 · 蜀道**
- 蜀兵（棋子上写「藤」）刀枪不入：**不能被炮吃掉**（其他棋子照常可以吃）。
- 蜀军所有棋子在山地中通行无阻。
- 劣势：藤甲怕火，会被吴军火攻连片烧毁。

> 演义里的藤甲兵本是南蛮乌戈国兀突骨的部队，这里设定为蜀平定南中后收编。

**吴 · 水军 · 火攻**
- 吴军所有棋子在水域中通行无阻。
- **火攻**（全局限 2 次，代替一步棋）：选择一枚与任意吴军棋子上下左右相邻的敌子（主公除外），将其烧毁；如果烧到的是藤甲兵，与它相连的敌方藤甲兵一起烧毁（火烧连营）。

于是每两家之间的边境都有自己的故事：魏蜀在秦岭拉锯（六出祁山），魏吴隔江对峙（赤壁、合肥），吴蜀在三峡相争（夷陵之战）。魏在开阔的荆州最强，蜀、吴守家最强。

## 五、行棋与胜负

- **行棋顺序**：蜀 → 吴 → 魏（最强的魏最后走）。
- **不能送将**：走完后，自己的主公不能处在任何对手的攻击之下。
- **吃将制**：三人局中，一家的走法可能让另一家直接吃到你的主公，你来不及应将。所以以「主公被吃」判定出局，而不是「将死」。
- **归降**：主公被吃的一方出局，其余棋子全部归降吃将者，并保留原有的兵种特性（例如魏吃掉蜀主公后，接管的藤甲兵仍然不怕炮）。归降的棋子右上角有原势力颜色的小圆点。
- **困毙**：轮到你时无棋可走，你出局，残部归降上一个行棋者。
- 出局一方的回合直接跳过。

获胜条件（任一）：

1. **一统天下**：只剩你一家。
2. **荆州霸业**：轮到你时，襄阳、江陵、江夏三座城上都站着你的棋子。也就是说，你要在三城驻军，并顶住两个对手各一步的反扑。
3. **回合上限**：各走 150 步（共 450 步）仍未分胜负时计分：子力（车 9、炮 4.5、马 4、士 2、象 2、兵 1）+ 每面城旗 3 分。棋子走上城池就插上己方旗帜，离开后旗帜仍在。

## 六、待试玩调整的参数

这是第一版规则，下面这些都是凭直觉定的，需要实际对局后再调：

- 火攻次数（`FIRE_ATTACK_USES`）、回合上限（`MAX_PLY`）、城旗分值（`CITY_SCORE`），在 `src/engine/factions.ts`；
- 行棋顺序（`TURN_ORDER`）；
- 中立地带的深度（`DEPTH`）、城池位置（`CITY_RANK`）、边境宽度，在 `src/engine/board.ts`；
- 魏马「平原不蹩腿」是否过强，藤甲兵「不怕炮」是否过强；
- 荆州霸业是否过易或过难。
